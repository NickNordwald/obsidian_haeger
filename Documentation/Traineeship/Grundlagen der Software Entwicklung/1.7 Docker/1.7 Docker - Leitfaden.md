# 1.7 Docker

*Richtwert: 1 Woche*

## ==Motivation==

Docker ist heutzutage eine der grundlegendsten Technologien und aus der modernen Softwareentwicklung nicht mehr wegzudenken. Ziel ist es zu verstehen, welche Probleme Docker löst, wie es "under the hood" funktioniert und wie man es aus Entwickler-Perspektive richtig einsetzt.

## Leitfaden / Stichworte

- Warum Containerisierung?
- Docker-Architektur: Docker Engine, Docker Daemon, Docker Client
- Docker-Objekte: Images, Container, Volumes, Networks
- Docker CLI: Grundlegende Befehle und Anwendung
- Dockerfile: Struktur und Best Practices
- Docker Volumes und Datenpersistenz
- Docker Compose: Multi-Container-Anwendungen

## Out of Scope

- Spezifische Cloud-Provider-Integrationen wie ECS
- Container-Orchestrierungs-Tools (z. B. Kubernetes)

## Kontrollfragen

- Was ist ein Container und wie unterscheidet er sich von einer VM?
- Erkläre den Unterschied zwischen einem Docker Image und einem Container.
- Wie erstellt man ein Docker Image? Beschreibe den Prozess und die Rolle des Dockerfiles.
- Was ist ein Multi-Stage Docker Build und warum sollte ich ihn in vielen Fällen nutzen?
- Was sind die Vorteile der Verwendung von Docker Compose?
- Wie funktioniert die Datenpersistenz in Docker? Erkläre Volumes.

## Aufgabe

Dockerisiere deine Anwendung und mache die gesamte Anwendung inklusive Datenbank über einen einzigen `docker-compose`-Befehl startbar.
