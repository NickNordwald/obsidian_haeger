## Kontrollfragen

- Wie definiert man eine abstrakte Klasse und warum würde man dies tun? Was unterscheidet die abstrakte Klasse von einer nicht-abstrakten?
	- Man definiert eine abstrakte Klasse, indem man ABC, und @abstractmethod implementiert. Die abstrakte Klasse muss dann von ABC erben und abstrakte Methoden müssen mit dem @abstractmethod deocrator versehen werden. Eine abstrakte Klasse ist eine Klasse, welches gemeinsames Verhalten verschiedener Klassen bündelt. So gesehen ist sie eine Design entscheidung. Eine abstrakte klasse kann im Gegensatz zu einer nicht-abstrakten Klasse nicht instanziiert werden.
- In vielen Programmiersprachen, wie z. B. Java, kann man Interfaces definieren. Wozu dienen diese und wie kann man vergleichbare Funktionalität in Python nutzen?
	- Diese dienen, um eine Schnittstelle zu programmieren i.e. um gemeinsames Verhalten nur zu erzwingen, aber nicht bereit zu stellen. In python könnten man dies entweder über eine abstrakte Klasse ohne geteilte Klassenmethoden und Konstruktor umsetzen oder über Protocol typing.
- Was unterscheidet ein Interface von einer abstrakten Klasse?
	- Ein Interface gibt keinen geteiliten Code vor und bietet auch gar nicht die Möglichkeit dazu.
- Warum ist es oft sinnvoller, Interfaces nach außen zu kommunizieren, als spezifische Klassen?
	- Weil wenn wir ein Interface als Schnittstelle verwenden können wir danach den Code deutlich einfach warten, weil wir die Konkreten Implementationen nur über das Interface bereit gestellt wurden, aber nicht voneinader abhängen.
- Was unterscheidet Kapselung und Abstraktion voneinander?
	- Abstraktion bezeichnet dass Konzept, dass ein Objekt nur aus den Attributen und Methoden besteht, welche für die jeweilige Aufgabe relevant sind und andere Eigenschaften weggelassen werden. Kapselung steht dafür, dass man innere Logik von der Schnittstelle, welche die Klasse bereitstellt abkapselt.
- Was sind „statische" Methoden? Wie, wann und warum nutzt man sie?
	- Statische Methoden sind Methoden, welche nicht auf das Objekt Bezug nehmen i.e. kein self nutzen. Mann nutzt sie indem man den decorator @staticmethod verwendet und wenn man eine Methode, welche zur Klasse sinnvoll zu klasse gehört auch wenn sie nicht dierekt auf ein Objekt bezug nimmt in dieser bündeln will.
- Was ist der Unterschied zwischen `@staticmethod` und `@classmethod` in Python?
	- @classmethod übergibt der Methode cls und hat damit Zugriff auf die Klasse selber. Damit kann man z.b. alternative Konstruktoren definieren weil das erlaubt die Klasse zu instanzieren.
- Was bedeutet Information Hiding im Kontext der objektorientierten Programmierung?
	- Information Hiding bedeutet, dass der User nicht wissen muss, was im Hintergrund der Klasse passiert.
- Was bedeutet Clean Code?
	- Das man gut lesbaren Code schreibt (Code wird serh viel öfter gelesen als geschrieben). Dabei hält man einge Grundproinzipen ein wie z.b. saubere Benennung von Variablen und Methoden, sinnvolle sparsame KOmmentare usw.
- Wie funktioniert Dependency Injection? Welche Probleme löst man damit?
	- Bei der Dependency Injection werden Klassen Schnittstellen übergeben mit welcher sie dann Funktionalität, welche benötigt wird zu Verfügung haben. Dies erlaubt zum Beispiel einfaches warten oder austauschen bestimmster Funktionalitäten, da die Implementierung getrennt ist von da wo es verwendet wird.
- Welches Problem lösen Dataclasses in Python?
	- Das definieren neuer Datentypen. Nimmt sehr viel overhead arbeit ab, wei konstruktore definieren, getter und setter und so weiter.
- Was sind „dunder"-Methoden in Python?
	- Es steht für double underscore funktionen und ist eine Sammlung von bestimmten Funktionen und Attributen, welche Python mitbringt.
