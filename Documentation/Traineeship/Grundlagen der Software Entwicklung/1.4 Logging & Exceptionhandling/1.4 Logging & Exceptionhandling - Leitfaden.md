# 1.4 Logging & Exceptionhandling

*Richtwert: 1–2 Tage*

## Motivation

==Logging ist hilfreich um das Verhalten unseres Systems zu tracken und kann beim Debuggen enorm hilfreich sein.==

Als Data Engineer stellt das Logging anderer Systeme außerdem oft eine wesentliche Datenquelle für uns dar. Logging wird nämlich nicht nur zum Debuggen genutzt, sondern auch für:

- (Performance-)Monitoring
- Analyse
- Nachvollziehbarkeit
- Datenschutz
- Compliance
- Audits

## Leitfaden / Stichworte

- ==Loggen von Exceptions==
- Parametrisierte Logs
- Logging in Theorie und Praxis (Context Python)
- Logging-Level
- Logging-Frameworks
- Exceptionhandling best practices
