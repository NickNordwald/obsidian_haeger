# 1.5 REST APIs & Layered Architecture

*Richtwert: 2 Wochen*

## Motivation

Im Wesentlichen besteht unser Projekt aktuell aus 2 Schichten:

- Einer "Repository"-Schicht, die die Schnittstelle zwischen unserem Programm und der Datenhaltung ==darstellt==
- Einer "Business Logic"-Schicht, in der das Kernverhalten unseres Programms definiert ist

Wie du spätestens in diesem Kapitel lernen wirst: Unser Code sollte diese (und bald weitere) Schichten klar definieren, darstellen und trennen.

Eine Schicht, die wir nun hinzufügen wollen, ist die "Presentation Layer" in Form einer REST API. Diese wird dazu genutzt, um von außen — via HTTP — auf unsere Anwendung zugreifen zu können. REST APIs stellen uns in der Regel CRUD-Funktionalität zur Verfügung. Was das genau bedeutet, wie es funktioniert und wie man es richtig implementiert, lernst du in diesem Kapitel.
