# Boulder App - Tech Stack

Teil der Discovery für die [[Boulder App]]. Gesetzt ist ein Backend in Python. Alles andere hängt von [[Boulder App - Features|Features]] und der Plattform-Frage ab und wird erst danach entschieden.

## Bausteine

Diese Bausteine braucht die App in jedem Fall. Für jeden wird später eine Technologie gewählt.

- Backend mit API
- Datenbank für Hallen, Wände, Routen, Bewertungen und Nutzer
- Speicher für Fotos und Videos
- Frontend mit interaktivem Grundriss und Wandfoto mit klickbaren Punkten
- Authentifizierung, falls es Accounts gibt
- Optional: Vision-Modell für die [[Boulder App - Routenerkennung|Routenerkennung]]

## Discovery-Fragen

### Plattform

- Muss es eine echte Android-App sein, oder reicht eine Web-App, die man auf dem Handy wie eine App nutzen kann?
- Ist iOS wichtig, z. B. weil Freunde ein iPhone haben?
- Braucht die App Funktionen, die nur nativ gut gehen, z. B. Kamera-Zugriff im Hintergrund oder Push-Benachrichtigungen?

### Vorwissen und Lernziele

- Welche Python-Frameworks kennst du schon? Im Vault gibt es z. B. Karten zum FastAPI-Tutorial.
- Wie weit bist du mit React? Es gibt den Task [[React Frontend fertig bauen]].
- Willst du lieber etwas Neues lernen oder schnell vorankommen?
- Sollen Docker und Kubernetes Teil des Projekts sein, als Übung für das Deutz-Projekt?

### Daten

- Hast du Erfahrung mit einer bestimmten Datenbank, z. B. PostgreSQL?
